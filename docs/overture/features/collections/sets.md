# Collection sets

A **collection set** creates one collection per value in its libraries: each
decade, year, genre, studio, network, country, origin country, original
language, streaming service, content rating, resolution, edition, label,
actor, director, writer, producer, production company, TMDB keyword, show
status or TMDB franchise; on Plex smart sets also each audio or subtitle
language, video or audio codec and audio channel layout.

A **custom** set lists its collections, each with its own criteria, such as A
to Z or Based on a book.

## Choosing values

Sets can keep the most common values, include or skip values, remove text from
names, and rename or merge values. The title template names each collection,
where `{value}s` turns 1990 into 1990s.

Changing **Split by** switches the title template, the group's name and, when
Plex alone can count the new values, **Evaluated by** to Plex. A smart set can
split by anything Overture can count, testing by label what Plex cannot.

Creating a set refuses a group that already is one and warns when another set
splits the same libraries alike or the group already holds collections; the
set preview names values whose title another collection already has.

## How a set behaves

A set's collections take their criteria and titles from the set; edit it in
**Collection groups**. A set runs on its schedule once it has been synced.

A collection whose value the set no longer selects, or the library no longer
holds, leaves the server and stays in Overture until the set selects its value
again. A collection its group's set made leaves only with its set, so it
offers neither delete nor orphan.

A set makes one collection per value across its libraries, offering the
fields and dimensions all of them share; see
[Collections across libraries](across-libraries.md).
